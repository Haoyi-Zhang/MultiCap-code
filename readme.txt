Electronic evidence: resource-semantics-complete-fusion

This directory is a self-contained repository for the internal article
"Capability-Indexed Materialization Bounds for Multiset Programs".  Start with
README.md.  It includes exact deterministic inputs, source/interpreters,
proof-producing compilers, independently written certificate checkers,
handwritten proofs, purpose-built proof kernels, negative controls, a
cross-file integrity audit, an 81-source reference audit, results, and seven
reproduction/check commands.  It needs no paper directory, external database,
solver, model service, or downloaded benchmark.  Finite checks and custom
kernels are described with their exact scope and are not presented as external
proof-assistant verification or independent review.
